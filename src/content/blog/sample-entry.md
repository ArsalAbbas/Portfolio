This is a draft. It appears while you run `npm run dev` and never in the built site. Write posts as Markdown (or MDX) files in `src/content/blog`, or run `npm run new-post "My title"` to get one with the frontmatter filled in.

## Headings, lists and links

Second-level headings break a post into parts. Lists get little diamonds:

- Short points read well
- Links look [like this](https://astro.build)
- **Bold** and _italic_ work as you'd expect

1. Numbered lists
2. Work too

> A quote, for when someone else said it better.

## Code

Code blocks are highlighted and follow the light and dark themes:

```ts
function greet(name: string) {
  return `Hello, ${name}!`
}
```
